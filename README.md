# 屿藏 · YU COLLECT

简洁现代的数字藏品展示原型，适配手机与桌面，人民币标价。

## 开发

要求 Node.js 20.19+ 或 22.12+（当前环境 Node.js 24）。

```sh
npm ci
npm run dev
```

云环境中使用 `export npm_config_cache=/workspace/.cache/npm` 指定可写缓存目录。

```sh
npm run build
npm run preview
```

首页、藏品详情和“我的”页采用一屏布局，无需纵向滚动。首页藏品按组切换，底部导航进入藏品目录、收藏与个人中心，搜索和分类位于弹层；藏品详情支持数量选择与收藏确认。“我的”页可编辑本机昵称、浏览收藏，并展示订单及帮助说明。收藏使用 localStorage 保存在当前浏览器。通过 URL hash 切换页面，无需服务端路由规则。

作品使用项目内原创生成的潮玩 IP 图片，同一系列通过配色区分版本。字体使用系统字体，不依赖外部图片或字体服务。首页参考用户提供的深色与青绿视觉方向，按钮采用简洁样式。

所有藏品、作者和发行数据为演示内容；不包含登录、支付、订单或区块链服务。购买入口只展示演示确认，不会扣款。订阅入口未接入邮件服务。

## 发布

GitHub Pages 使用 `gh-pages` 分支的根目录，仓库路径为 `/lukas/`。发布构建使用 `npm run build -- --base=/lukas/`，将 dist 内容更新到发布分支。源码在 main 分支。
